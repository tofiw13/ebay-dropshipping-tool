🔌 Canlı eBay datası necə qoşulur?

İndi proqram nümunə məlumatla işləyir. Canlı eBay qiymətləri/satışları üçün eBay-in pulsuz API-sini qoş:

  1. developer.ebay.com saytında pulsuz developer hesabı yarat.
  2. "Application keys" bölməsindən App ID (Client ID) və Cert ID al.
  3. Browse API (məhsul axtarışı) və Marketplace Insights (satış statistikası) icazələri istə.
  4. Bu açarları öz komputerində kiçik bir backend-ə (Node/Python) qoy — API açarı brauzerdə açıq saxlanmamalıdır.
⚠️ Təhlükəsizlik: API açarını birbaşa bu HTML faylına yazma — hamı görə bilər. Backend (server tərəfi) lazımdır.
🛡️ eBay qaydası: dropshipping üçün məhsulu topdan təchizatçıdan götür (SaleHoo, CJ Dropshipping və s.). Amazon/AliExpress-dən pərakəndə alıb satmaq qadağandır.
